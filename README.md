# 🚇 Metro Project — Beta

Минималистичная веб-песочница и конструктор схем метрополитена в браузере для проектирования транспортных сетей.

## ✨ Основные возможности Beta

- **Холст и геометрия:** Бесконечный холст с зумом, сетка (`45°/90°`), импорт фоновых карт и плавные дуги перегонов.
- **Станции и линии:** Пересадочные узлы, пешеходные переходы, «пеньковый» стиль станций, кодовые маркеры и автоматические мосты через реки.
- **Маршрутизатор:** Поиск кратчайшего пути с анимацией, расчетом расстояния и времени (`~XX мин`), линейка и масштаб мира.
- **Экспорт:** Таймлапс-анимация строительства с записью в **WebM (60 FPS)**, темная/светлая тема и выгрузка в **PNG** / **JSON**.

*Полную документь и детальное описание управления можно найти в файлах проекта или в репозитории.*

## 🚀 Дорожная карта (Roadmap)

- [x] **Alpha** — базовый движок, сетка, переходы, маршруты и экспорт.
- [x] **Beta** — фоновые подложки, изогнутые перегоны, мосты, линейка и таймлапс-видео.
- [ ] **Release** — мобильная адаптация и финальная полировка интерфейса.

## 🛠️ Технологии

Создано на **HTML5 Canvas**, **CSS3** и **Vanilla JavaScript** без сторонних фреймворков.
