# 🚇 Metro Project — Alpha

Минималистичная веб-песочница и конструктор схем метрополитена в браузере для создания транспортных сетей без установки тяжелых программ.

## ✨ Что уже работает в Alpha

- **Холст и режимы:** Бесконечный холст с зумом и перемещением, а также классическая сетка (углы 45°/90°/180°) и свободный режим строительства (`G`).
- **Сеть и маршруты:** Многоцветные станции на пересечениях, пешеходные переходы, волновой маршрутизатор с поиском кратчайшего пути и легенда линий.
- **Оформление и правки:** Умные подписи станций под 45°, слой ландшафта (реки), точечный ластик, темная/светлая тема, отмена действий (`Ctrl + Z`) и автосохранение.
- **Экспорт:** Сохранение прогресса в браузере и выгрузка схем в формате **PNG** или **JSON**.

## 🎮 Быстрое управление

- **Станция / ветка:** левый клик по холсту (завершить ветку — ПКМ или `Esc`).
- **Спец. инструменты:** переходы и маршруты активируются через соответствующие режимы между станциями.
- **Названия и сетка:** двойной клик по станции для переименования, клик по линии в легенде для названия ветки, `G` — сетка, `Ctrl + Z` — отмена.
- **Навигация:** `Пробел + ЛКМ` или колесико мыши для перемещения и масштабирования.

## 🚀 Дорожная карта (Roadmap)

- [x] **Alpha** — базовый движок, режимы сетки, переходы, маршруты, легенда, реки и экспорт.
- [ ] **Beta** — визуализация мостов и тоннелей при пересечении с реками, оптимизация подписей и исправление багов.
- [ ] **Release** — расширенные настройки экспорта, мобильная версия и полировка интерфейса.

## 🛠️ Технологии

Проект создан на **HTML5 Canvas**, **CSS3** и **Vanilla JavaScript** без сторонних фреймворков.
